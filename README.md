# Loomy for magpie

**10 个模型 · 三种登录 · 三笔积分一分不落**

讯飞 Loomy 的编程订阅接进 magpie：对话、看图、工具调用、思考档位；
积分按 magpie 的调度规则如实上报，该领的新手任务和邀请奖励自动领。

```
今日积分   ████████░░  4014 / 5000        ← 决定现在能不能用这个号
永久积分                5500        (附加)  ← 不会过期
新手任务                可领 9500   (附加)  ← 一次性，领完就没了
```

---

## 为什么选这个

**积分算得准。** 空号显示 0，不会因为「看起来额度很足」被 magpie 优先派活；
有余额的号按真实消耗排队。这一栏是 `used` 决定的路由输入，报错一个数字，
整个路由顺序就跟着错。

**多领两笔钱。**
- **新手任务 10,000 分** —— 卡片上直接显示「可领 9500 积分（7 项待完成）」，签到后自动到账
- **邀请码 5,000 分** —— 添加新账号时自动带本机老账号的邀请码，**双方各得 5000**

**不用重新登录。** 凭据格式与旧插件相通，装上就能用，登录态原样带过来。

**免费模型标得对。** `spark-x2.6` / `spark-x` 是 0 倍率（限时免费），
插件如实上报 `free`，路由组用「免费优先」时它们会被真正排在前面。

## 供应商

### 登录

| 方式 | 适用 |
|---|---|
| **桌面端导入**（推荐） | 本机装着 Loomy 客户端并已登录 —— 点一下，不收短信 |
| **手机号 + 短信** | 没装客户端 |
| **粘贴 session** | 想手动导 |

会话固定 **14 天**，Loomy 没有续期接口，到期后需重新登录一次。
插件不会假装能自动续 —— 否则 magpie 会一直以为可用，你反而等不到「请重新登录」的提示。

### 三笔积分

| | 怎么来 | 影响路由吗 |
|---|---|---|
| **今日积分** | 每天 5000，北京时间 0 点重置，用掉不回补 | **是** —— 只有它决定现在能不能用这个号 |
| **永久积分** | 注册 + 新手任务，不会过期 | 否（附加） |
| **新手任务** | 8 项任务合计 10,000 分，一次性 | 否（附加） |

为什么这么分：今日池每天清零，用光就是没了；永久积分不过期，不该因为它多就优先烧；
新手任务领一次就结束，更不能当常规额度。

### 签到

magpie 按北京时间每天调一次，签到同时会刷新当天额度，并**自动领取新手任务里已完成的那几项**。
结果显示具体数字，不是含糊的成功/失败：

```
今日额度已刷新（3479/5000 积分）· 新手任务 +500 分
```

### 加第二个账号

Loomy 的邀请机制：**邀请好友双方各得 5000 积分**。

添加新账号时，插件会自动从本机已有账号里挑一个邀请码带上去 ——
用没用过的、还有余量的、用得最少的那个。你只要正常「添加账号」，那 5000 分自己就到手。

## 安装

在 magpie 的 **插件 → 发现** 里搜 `Loomy`，点**安装**。

⚠ 先卸掉别的 Loomy 插件 —— 两个插件抢同一个 `loomy` 供应商会互相打架。

装完 `magpie plugin list` 应看到：

```
magpie-plugin-loomy-auth  on
  loomy (Loomy, 10 models)  signed in as 189****8051
```

## 常见问题

**积分显示 0，但官方 App 里还有？**
① 今日额度用光，等北京时间 0 点重置；② 那是**新手任务**，卡片上单独一行「可领 XXXX 积分」，签到后到账。

**显示「登录已失效」？**
会话 14 天到期，重新登录一次即可。

**会花我的积分吗？**
不会。插件只读余额、签到、领任务奖励。消耗积分的是你通过 magpie 发的对话请求。

**能看到我的什么？**
Loomy 登录态（存在 magpie 自己的凭据文件里）、积分/模型/任务读数。
直连 `loomyad.xunfei.cn` 与 `account.xfinfr.com`，不经任何第三方中转。
邀请码功能读同文件里其它 Loomy 账号的码，仅只读，不外发。

**装完没反应？**
`magpie plugin list` 确认只有一个 `loomy`。改完配置重启一次 magpie 最稳（登录态不丢）。

## 卸载

`magpie plugin rm magpie-plugin-loomy-auth`

登录态留在 magpie 的凭据里，重装即恢复。
